# 按键与 LED 操作（无需断电切换模式）

适用于冻结版。前进朝原车尾，后退朝原车头。

## 一个按钮的操作

| 当前状态 | 短按后松手 | 长按约 0.8 秒 |
| --- | --- | --- |
| 电机已关闭、待机 | 准备 3 秒，进入平衡 | 基本／避障模式切换，不启动电机 |
| 正在准备 | 取消准备 | 取消准备并保持停止 |
| 平衡待命或任务已完成 | 执行当前选中的任务 | 关闭电机 |
| 任务运行中 | 平滑结束任务并继续平衡 | 关闭电机 |
| 任务异常、仍在平衡 | 先清除任务异常，下次短按才开始任务 | 关闭电机 |

**运行中想换模式：长按停机 → 松手 → 再长按切模式。** 无需关电、复位或拔插电源。一次按住只执行一次动作，停机后继续按住不会误切模式；切换后松手也不会触发启动。切换模式只在确认输出关闭且没有准备/保存操作时执行。

上电默认基本模式，原来的“按住按钮上电选择避障”已取消。上电时即使按钮被按住，也必须先松手，再进行正常操作。选中的模式会在本次通电内保留，长按停机、任务完成或取消不会把模式恢复为基本。

## PC13 状态灯

| 灯态 | 含义 |
| --- | --- |
| 每组闪 1 次，间隔约 2 秒 | 待机，基本五秒任务 |
| 每组闪 2 次，间隔约 2 秒 | 待机，避障任务 |
| 快闪 | 正在准备 3 秒 |
| 常亮 | 正在平衡待命，或任务完成后继续平衡 |
| 慢闪（亮半秒、灭半秒） | 任务正在执行，包括避障等待和后退 |
| 四连闪后停顿 | 准备未通过、控制保护或任务异常 |

现有 PC13 一颗状态灯就足够区分模式和运行状态，不需要增加 LED。**PA7 仍作为有效近距障碍指示灯**，不改作模式灯；OLED 仍显示距离。外接 PA7 指示灯的安装情况以实物为准。

## 任务操作

先拔掉 ST-Link，保留原供电。待机时长按选好模式，观察一闪／两闪，再短按、松手，扶稳等待 3 秒进入平衡；再短按开始任务。

- 基本模式：朝新车头前进 5 秒，停车后继续平衡；再次短按可重复。
- 避障模式：探头须朝新车头。接近障碍约 18cm 时停车，停稳平衡 5 秒，再朝新车尾后退 10cm，随后继续平衡。
- 任何准备或运行阶段，长按约 0.8 秒可关闭电机。若准备未通过，扶稳后重新短按即可。

所有 PID、限幅、补偿、零点和任务参数保留，电脑调参和“保存到车”继续可用。相关功能已完成实车验证。
