# 停车和后退保持操作

本版已烧录，按键和前后方向沿用原操作，PID 和第 68 版保存参数保留，并行速度 Ki=0.5。

- 只短按一次，三秒准备后进入原地平衡。位置保持建立范围放宽，通常满足条件 100ms 后锁定。
- 再短按执行任务。任务中短按停车，目标速度在 300ms 内平滑降至零，同时开始保持停车目标位置。
- 后退到目标附近（原来的 ±0.5cm 到点范围）即停止行驶参考并接管位置保持，保持原目标点，减少继续滑行。
- 保持位置的自由范围缩到 ±0.5cm，超出即产生温和的回中目标；回中目标仍最多 3cm/s。
- 长按约 0.8 秒仍是关闭电机；停机松手后再次长按才切换基本/避障模式。LED 操作不变。

停车/到点接管须满足倾角≤4°、角速度≤25°/s、车速≤6cm/s；倾角≥5°、角速度≥35°/s或车速≥8cm/s仍退出位置保持。倾倒及姿态失效等电机保护未修改。接管位置保持与确认实际停稳分别处理：实际轮速、姿态连续满足原停稳条件500ms才确认停车，避障随后仍需停稳保持五秒才后退。

请拔掉 ST-Link，在平整地面按原操作观察原地漂移、短按停车以及避障后退到点的偏移。软件检查已通过；用户反馈停车效果很好，具体位移未量化。本版不再要求采集运行记录；若仍有问题，直接说明哪一种操作和偏移现象即可。

电脑调参和保存到车保留；已运行的旧面板进程需要重新启动才能加载新固件清单。
